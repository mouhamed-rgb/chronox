# نبض | PULSE

تطبيق Flutter عربي لإدارة بطاقات التذكير، بواجهة داكنة نيونية وحفظ محلي باستخدام Hive.

## الوظائف المحفوظة
- إنشاء البطاقات وتعديلها وحذفها، مع العنوان والتفاصيل والموعد.
- ثلاثة مستويات للأهمية مع قنوات تنبيه منفصلة.
- تكرار تنبيهات المستويات الأعلى، والتنبيه الكامل للمستوى الأعلى، والاهتزاز.
- تأجيل التنبيه، وإكمال البطاقة، واختبار التنبيهات.
- قفل التطبيق والبطاقات برمز PIN من أربعة أرقام.
- شاشة رئيسية عربية، بطاقات زجاجية، خلفية متحركة، وإعدادات التأجيل.

## تحسينات هذا الإصدار
- ترقية تخزين PIN القديم تلقائياً إلى hash مملح وتكراري عند أول تحقق ناجح.
- تأخير متزايد بعد محاولات PIN الفاشلة.
- منع التنقل إلى شاشة التنبيه قبل فتح قفل التطبيق، والتحقق من PIN للبطاقات المقفلة.
- حماية إجراء إكمال البطاقة المقفلة من تجاوز التحقق.
- توليد معرّفات بطاقات لا تتصادم مع البطاقات الحالية وتبقى ضمن مجال Android notification IDs.
- ضبط حدود مستوى التنبيه ومدة التأجيل.
- إصلاح إعدادات Android الخاصة بالأذونات وCore Library Desugaring، وجعل سكربت التصحيح قابلاً لإعادة التشغيل.
- إضافة اختبار تحويل بيانات البطاقة وفحوصات التحليل إلى CI.

## بناء APK
1. افتح تبويب **Actions** في GitHub.
2. اختر **Build PULSE APK**.
3. بعد نجاح التشغيل، افتح **Artifacts**.
4. نزّل `pulse-release-apk`.

ملف APK لا يُرفق بالمستودع؛ يتم إنتاجه كـ Artifact من GitHub Actions.
